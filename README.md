# Klar

Задачи, которые звонят вовремя. Android-приложение на Flutter: списки, подзадачи, повторения,
несколько напоминаний на задачу — каждое может звонить как настоящий будильник (поверх экрана
блокировки, со своим звуком, вибрацией и нарастанием громкости) или приходить обычным уведомлением.

## Запуск

```shell
fvm install            # Flutter из .fvmrc
fvm flutter pub get
fvm flutter run
```

## Генерация кода

```shell
fvm dart run build_runner build --delete-conflicting-outputs   # drift
fvm flutter gen-l10n                                           # строки из lib/l10n/app_ru.arb
```

## Возможности

- Списки, приоритеты, подзадачи, повторения (каждые N дней / недель по дням / месяцев / лет, с датой окончания).
- Несколько напоминаний на задачу: «Будильник» (полноэкранно поверх блокировки, звучит до ответа,
  проходит «Не беспокоить») или «Уведомление». Готово / Отложить работают прямо с экрана будильника
  и из шторки, даже когда приложение выгружено.
- Звук: встроенные Fjord / Björk / Frost, системные мелодии, свой файл; громкость «не тише N%»,
  плавное нарастание, 5 вариантов вибрации, автоотключение; переопределение на уровне задачи.
- Ближайшая задача в шторке: постоянное уведомление с обратным отсчётом и кнопкой «Готово».
- Карточка «Надёжность» в настройках: уведомления, точные будильники, полноэкранный звонок, батарея.

## Архитектура

- `lib/` — Flutter: UI, база (drift), `AlarmPlanner` считает все будущие сигналы.
- `android/app/src/main/kotlin/com/umartin/klar/alarm/` — нативный движок будильников: хранит
  расписание в device-protected storage, взводит AlarmManager, звонит через foreground service,
  обрабатывает «Готово / Отложить» без запущенного Flutter и переживает перезагрузку.
- Связь — канал `klar/alarms`: Flutter отправляет полный план (`replaceAll`), натив возвращает
  события «Готово», которые Flutter применяет к базе перед следующей синхронизацией.

## Проверка на устройстве

```shell
P=com.umartin.klar
adb shell dumpsys alarm | grep -A4 $P            # взведено не больше 3 системных будильников
adb shell dumpsys activity services $P           # RingService: systemExempted, NextTaskService: specialUse
adb shell dumpsys deviceidle force-idle          # Doze: будильник всё равно звонит вовремя
adb reboot                                       # после загрузки расписание восстанавливается
```

`adb shell am force-stop` по правилам Android отменяет все будильники приложения — они
восстанавливаются при следующем запуске.
